= Local database access

Start the database from `DookuG-new/dev` before connecting. The local Compose file binds database ports to `127.0.0.1`; use the values configured in `dev/.env` if you changed the defaults.

== PostgreSQL

* Host: `localhost`
* Port: `LOCAL_PORT` (default: `5432`)
* Database: `DB_NAME` (default: `dookug_db`)
* Schema/user: `DB_OWNER` (default: `dookug_owner`)
* Password: `DB_OWNER_PASSW` from `dev/.env`
* JDBC URL: `jdbc:postgresql://localhost:5432/dookug_db` (adjust for overrides)

The `dookug` application schema is also created by the migration. Its password is configured by `dookug_PASSWORD` in `dev/.env`.

== Oracle XE

Connect to the pluggable database service `XEPDB1`, not the XE container database.

* Host: `localhost`
* Port: `ORACLE_PORT` (default: `1521`)
* Service name: `XEPDB1`
* JDBC URL: `jdbc:oracle:thin:@//localhost:1521/XEPDB1` (adjust for overrides)

Use the configured administrator credentials for administrative access. The migration creates the `dookug` schema and service user; their passwords are configured by `dookug_PASSWORD` and `dookug_SERVICE_PASSWORD` in `dev/.env`.
