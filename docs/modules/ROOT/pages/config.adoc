= Configurations

The project uses separate configuration files for image builds, database setup, and migrations.

* Project root `.env` (image builds):
  - **VERSION**: Tag applied to both project Liquibase images (_default: `2.2.0-SNAPSHOT`_).
  - **DOCKER_REPOSITORY**: Registry prefix for the project images (_default: `dockerhub.icellmobilsoft.hu`_).
  - **DOCKER_RUNTIME_LIQUIBASE**: Base Liquibase image (_default: `liquibase/liquibase:4.33`_).
  - **DOCKER_DOOKUG_CRESCHEMA_LIQUIBASE** and **DOCKER_DOOKUG_LIQUIBASE**: Image names for schema creation and schema migrations; derived from the registry and project version.
  - **DBDWH_IMAGE_VERSION**: PGTools version setting (_default: `1.0.0`_).
* Each installer directory has its own `.env` file:
  - `docker/dookug_db/dookug_creschema/.env` configures the connection used to create the schema and users: **JDBC_URL**, **CRESCHEMA_USER**, **CRESCHEMA_PASSW**, **DOOKUG_SCHEMA**, **DOOKUG_SCHEMA_PASSW**, **DOOKUG_SERVICE_PASSW**, and optionally **DOOKUG_TABLESPACE**.
  - `docker/dookug_db/dookug/.env` configures the schema migration connection: **JDBC_URL**, **DOOKUG_SCHEMA**, and **DOOKUG_SCHEMA_PASSW**.
  - Set the JDBC URL and credentials for the target database before running either installer. The checked-in values are examples; replace passwords and connection details for your environment.
* Local development `dev/.env`:
  - **POSTGRES_IMAGE**, **LOCAL_PORT**, **PGPASSWORD**, **DB_NAME**, **DB_OWNER**, and **DB_OWNER_PASSW** configure the PostgreSQL container and database.
  - **ORACLE_IMAGE**, **ORACLE_PORT**, **ORACLE_CONTAINER_NAME**, and **ORACLE_PASSWORD** configure Oracle XE.
  - **DOOKUG_PASSWORD** and **DOOKUG_SERVICE_PASSWORD** configure the project schema and service user passwords.
  - The local scripts support PostgreSQL and Oracle. Their default images are PostgreSQL `17-alpine3.22` and Oracle XE `21.3.0-xe`.
