* Technologies:

  ** Components and their versions (from the project defaults):
  - Local development PostgreSQL: 17-alpine3.22
  - Local development Oracle XE: 21.3.0-xe
  - Liquibase runtime image: 4.33
  - PGTools version setting: 1.0.0

  ** Installation model:
  - The project builds separate Liquibase images for DookuG schema creation and DookuG schema migrations.
  - Local development scripts initialize PostgreSQL or Oracle XE and apply both changelogs.
